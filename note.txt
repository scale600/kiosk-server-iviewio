1. Video & Media (dedicated URL required)
YouTube: youtube.com/embed/VIDEO_ID format only

Vimeo: player.vimeo.com/video/VIDEO_ID format

Twitch: live streams and chat embed allowed

SoundCloud: audio player embed allowed

2. Maps & Documents
Google Maps: 100% allowed when using the "Embed a map" code from the share menu

Google Docs/Sheets/Forms: use the iframe code provided after "Publish to the web"

Notion: public pages can be embedded via some embed tools (custom domain, etc.)

3. Development & Design Tools
CodePen / JSFiddle: embed code execution results

GitHub Gist: for embedding code snippets

Figma: design prototype embed allowed

4. SNS & Community (widget/post form)
X (Twitter): embed specific tweets or timelines

Facebook / Instagram: embed code for specific posts

Reddit: embed specific posts

5. Informational & Others
Wikipedia: sometimes allowed under specific settings, but limited by browser policy

Weather.com / AccuWeather: provide weather widgets

💡 Tip: how to quickly check if embedding is allowed
Most sites block direct embedding of their main page (www.google.com, etc.) for security (clickjacking prevention).

Check whether the site has an official "Share" or "Embed" button.

URLs from that button have X-Frame-Options disabled, so embedding works.
